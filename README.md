📊 Eternal Limited (Formerly Zomato Limited) – Financial Ratio Analysis

This project presents a comprehensive financial ratio analysis of Eternal Limited (formerly Zomato Limited), comparing performance between FY2024 and FY2025.

The analysis is built using an Excel-based financial model and converted into a structured PowerPoint presentation with clear interpretations and insights.

🚀 Key Highlights
📈 Revenue Growth: ₹12,114 Cr → ₹20,243 Cr (+67%)
💰 Net Profit Growth: ₹351 Cr → ₹527 Cr (+50%)
💼 Cash Reserves: ₹18,824 Cr (+54%)
📊 EPS Growth: ₹0.41 → ₹0.60 (+46%)
